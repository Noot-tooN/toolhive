## thv secret bitwarden

Manage the local Bitwarden access token

### Synopsis

Store or remove the Bitwarden Secrets Manager bootstrap token in the native OS credential store.

This credential is separate from remote Bitwarden secrets and local OAuth storage.
BWS_ACCESS_TOKEN, when set, overrides the saved credential.
