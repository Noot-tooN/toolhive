## thv secret bitwarden logout

Remove the saved Bitwarden access token

### Synopsis

Remove only the saved local Bitwarden access token.

This does not revoke the token in Bitwarden, remove BWS_ACCESS_TOKEN from the
environment, or change remote secrets or local OAuth credentials.

```
thv secret bitwarden logout [flags]
```
